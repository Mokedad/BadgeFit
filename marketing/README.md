# BadgeFit marketing

## Reels and TikToks

`reels/reels.cjs` holds the reels as slides; `reels/make-reels.cjs` renders them to vertical
1080×1920 MP4s with a caption file each:

```bash
node marketing/reels/make-reels.cjs        # all → marketing/reels/out/
node marketing/reels/make-reels.cjs 03     # one reel
```

The videos have no sound on purpose: add a trending sound inside Instagram or TikTok when you
post (licensed there, and it helps reach). Add a new reel by copying a block in `reels.cjs`.
The phone screenshots come from `badgefit-site/img/`.

Posting tips: the first 1.5 seconds decide everything, so the hook is the first slide. Post at
6-8 am or 6-8 pm, when applicants train. Pin a comment with the link. Reply to every comment
in the first hour.
