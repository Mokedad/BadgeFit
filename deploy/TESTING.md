# Test BadgeFit on your phone and computer

You need the server running first (deploy/README.md, steps 1-3). Then work down this list and
tick each one. Note anything that looks wrong (a screenshot helps) and send it back.

## A. Web app (computer)

| # | Do this | You should see |
|---|---|---|
| 1 | Open `https://app.YOURDOMAIN` | The sign-in screen, a padlock in the address bar |
| 2 | Create new profile → Password → your name and a strong password | You land on Home: "Hi <name>" and the BadgeFit card |
| 3 | Settings → scroll to Admin dashboard | It is there (the first profile is the admin) |
| 4 | Open `https://YOURDOMAIN` | The BadgeFit website; "Start training free" opens the app |

## B. Phone app (iPhone home screen)

| # | Do this | You should see |
|---|---|---|
| 5 | On the iPhone, open `https://app.YOURDOMAIN` **in Safari** | The sign-in screen |
| 6 | Share ⬆️ → **Add to Home Screen** → Add | A BadgeFit icon on your home screen |
| 7 | Open BadgeFit **from that icon**, sign in | Full screen, no Safari bars |

Android: open the address in Chrome → ⋮ → **Install app**.

## C. Your PCT setup (in the phone app)

| # | Do this | You should see |
|---|---|---|
| 8 | Home → BadgeFit card → ⭐ Today → set **Test date** | "28 days to go" (or whatever is left) |
| 9 | Pick Beginner or Intermediate → **Build my programme** | Today's session in the week card; Plan tab shows weeks 1-12 |
| 10 | 📅 Plan → turn on **Beep focus** if the beep is your weak point | Saturday becomes intervals |
| 11 | 🍽️ Food → weight 110, height, age, sex | Calories around 2,700 for fat loss, protein 242 g |
| 12 | 🎯 Tests → log each standard you can test now | Readiness ring and the symbols turn green or orange |
| 13 | ⚖️ Body → + Weight | Start → now → change |

## D. Meal reminders 🔔

| # | Do this | You should see |
|---|---|---|
| 14 | 🍽️ Food → 🔔 Meal reminders → switch on | iPhone asks "Allow notifications?" → **Allow** |
| 15 | Set Breakfast to **2 minutes from now** | Within ~2-3 minutes: "🍳 Breakfast" on your lock screen |
| 16 | Tap that notification | BadgeFit opens on 🍽️ Food |
| 17 | Set your real times back | (Pre-workout 30-45 min before your usual run) |

If nothing arrives: iPhone Settings → Notifications → BadgeFit → Allow Notifications is on, and
Focus/Do Not Disturb is off. Then switch the reminders off and on again in the app.

## E. Training

| # | Do this | You should see |
|---|---|---|
| 18 | Today → **Start** (or the green ▶ at the bottom) → do a set, tick it | The set is logged, the rest timer runs |
| 19 | 🏋️ Reps → enter weight and reps | Move down / Stay / Move up and Jarvis's line |
| 20 | 🍽️ Food → paste a Spotify playlist link in 🎵 Music → Save | The player shows; during a workout it sits under the header |
| 21 | 🩹 Care → type "shins" | Shin splints: why, what to do, when to see a physio |
